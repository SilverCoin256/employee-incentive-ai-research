# employee-incentive-ai-research

Code and evaluation pipeline for:

**"A Governance Aware Framework for Auditing Calibration Explainability and Fairness in HR Attrition Prediction Models"**
*Discover Artificial Intelligence (Springer Nature)*

---

## What this is

A single reproducible pipeline that audits an HR attrition model across calibration,
uncertainty, explainability, and fairness. The contribution is the evaluation
architecture, not a new model. The IBM HR Analytics dataset is synthetic and public,
chosen so the whole pipeline can be replicated without data-access barriers.

**Every number in the manuscript is produced by one run of `pipeline.py` (seed 42).**
It writes a single machine-readable output, `results/results.json`, and regenerates
every figure (`figures/`) directly from the run's raw predictions — no values are
embedded in the plotting code, and no second results file exists.
[`TRACEABILITY.md`](TRACEABILITY.md) maps each reported table, figure, and in-text
value to its named key in `results/results.json`.

```
pip install -r requirements.txt
# place the dataset at data/ibm_hr_attrition.csv (see data/README.md)
python3 pipeline.py        # -> results/results.json + figures/*.{png,pdf,svg}
```

## Repository structure

```
pipeline.py          the single authoritative reproducer (everything below in one run)
results/results.json every reported value, keyed (see TRACEABILITY.md)
figures/             all manuscript figures, regenerated by pipeline.py
data/README.md       how to obtain the dataset (SHA-256 pinned in results.json)
legacy/              earlier scripts retained for provenance only — not used
```

Preprocessing is leakage-controlled: encoding/scaling/imputation are fit inside each
training fold (scikit-learn `Pipeline`/`ColumnTransformer`); CatBoost uses native
categorical handling. Protected attributes (gender, age, marital status) are excluded
from the predictor set and used only for fairness auditing.

---

## What one run computes

- Stratified 5-fold CV benchmark for CatBoost / logistic regression / random forest /
  majority baseline, each under two class-weighting configurations, with fold-SD,
  fold-based 95% CIs, and pooled ECE per configuration (`bench`)
- A prespecified model-selection rule (calibration gate → max CV AUC → one-SD
  parsimony), applied and logged verbatim (`model_selection`)
- Overfitting assessment: per-model train/CV/holdout optimism gaps (`overfit_gaps`)
  and a CatBoost regularization sweep (`cb_regularization_sweep`)
- Uncertainty: conditional bootstrap of holdout predictions (`bootstrap_auc_ci`) and
  100 repeated full-pipeline train/test splits with complete refitting
  (`repeated_splits`)
- Calibration: pooled-CV ECE with bootstrap CI, adaptive-bin variant, unweighted
  sensitivity with CI, Brier skill vs. the base-rate reference
- XAI validation with repeated controls: SHAP–permutation Spearman across 10
  permutation seeds (`xai_spearman`), top-5 vs. 20 random 5-feature masking
  (`xai_masking`), 10 shuffled-label refits (`xai_shuffled_label`)
- Fairness: DIR / Cramér's V / DPD / EOD per attribute with subgroup sizes and
  1,000-resample bootstrap CIs (`fair_full`), plus the same diagnostics for the
  selected logistic regression (`fair_lr_unweighted`)
- Proxy MI audit with 200-permutation nulls (z, empirical p) (`mi`, `mi_null`)
- Governance-threshold sensitivity sweeps for every cut-off used in the paper
  (`threshold_sensitivity`)
- Segmentation diagnostics (KMeans / PCA+KMeans / GMM / DBSCAN) (`seg`)
- Run provenance: seed, dataset SHA-256, library versions (`provenance`)

Model AUCs overlap in their fold-based intervals. Under the prespecified rule the
deployment-preferred model is unweighted logistic regression; CatBoost is the
audit-demonstration subject representing the opaque model class the framework is
designed to audit. All governance cut-offs are illustrative escalation defaults;
`threshold_sensitivity` records how every flag behaves as each cut-off is swept.

## Limitations

The IBM HR dataset is synthetic and not from a real organization. All results
demonstrate evaluation-framework mechanics; generalization to real workforces requires
external validation with appropriate data provenance. See the manuscript's Scope
Conditions.

---

## Environment

Tested on Python 3.14 (catboost 1.2.10, scikit-learn 1.8.0). Core dependencies:
catboost, scikit-learn, numpy, pandas, scipy, matplotlib, shap.
