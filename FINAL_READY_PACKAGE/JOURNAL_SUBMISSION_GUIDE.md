# Journal Submission Guide

This guide explains how to submit the manuscript package to a journal submission portal.

## Primary manuscript files

Submit these files when requested by the journal system:

- **Main manuscript PDF**: `FINAL_POLISHED_MANUSCRIPT.pdf`
- **Editable manuscript file**: `FINAL_POLISHED_MANUSCRIPT.docx`
- **LaTeX source, if requested**: `final_submission_manuscript.tex`
- **Bibliography, if requested**: `references_verified.bib`
- **Supplementary appendix**: `supplementary_appendix.md`
- **Cover letter**: `cover_letter.md`

## Files not to submit to the journal

Do not submit these unless the portal specifically asks for them:

- **GitHub upload guide**
- **Internal README drafts**
- **Development notebooks**
- **Virtual environments**
- **Raw cache folders**
- **Placeholder export files**
- **Any unrelated project files**

## Recommended article type

Select the closest available category to:

- **Research Article**
- **Original Research**
- **Applied Artificial Intelligence Research**
- **AI Governance / Responsible AI / Machine Learning Application**

If the system asks for subject areas, choose options closest to:

- **Applied Artificial Intelligence**
- **Responsible AI**
- **Machine Learning**
- **Explainable AI**
- **AI in Organizations**
- **Human Resource Analytics**

## Suggested title metadata

Use the manuscript title exactly:

`A Constrained Auditing Pipeline for Predictive HR Analytics: Explainability, Fairness Diagnostics, and Structural Limitations Demonstrated on a Synthetic Benchmark`

## Suggested keywords

Use these keywords:

- **Explainable AI**
- **HR analytics**
- **Attrition auditing**
- **Fairness diagnostics**
- **Responsible AI**
- **Constrained pipeline**
- **Small-sample variance**
- **Synthetic benchmark**
- **Calibration**

## Suggested abstract metadata

Copy the abstract directly from the final manuscript. Do not rewrite the abstract in the portal unless the journal has a strict word limit.

## How to upload the manuscript

1. Start a new submission in the journal portal.
2. Choose the article type closest to **Research Article**.
3. Paste the exact title from the manuscript.
4. Paste the abstract from the manuscript.
5. Add the suggested keywords.
6. Upload `FINAL_POLISHED_MANUSCRIPT.pdf` as the main manuscript if the portal accepts PDF.
7. Upload `FINAL_POLISHED_MANUSCRIPT.docx` as the editable manuscript file if requested.
8. Upload `supplementary_appendix.md` as a supplementary file.
9. Upload figures separately only if the journal portal requests separate figure files.
10. Upload `references_verified.bib` only if the portal asks for bibliography/source files.
11. Paste or upload `cover_letter.md` in the cover-letter step.
12. Review the generated submission proof before final submission.

## Cover letter use

Use `cover_letter.md` as the cover letter. If the portal provides a text box, paste the cover letter text into the box. If the portal requests a file, upload `cover_letter.md` or convert it to PDF if required.

## Supplementary file description

When asked to describe the supplementary appendix, use:

`Supplementary appendix documenting reproducibility artifacts, empirical outputs, structural index definitions, clustering summaries, fairness diagnostics, and interpretation limits.`

## Figure and table upload guidance

If the journal asks for separate figures, upload the contents of the `figures/` folder.

If the journal asks for separate tables, upload the contents of the `tables/` folder.

If the journal accepts embedded figures and tables in the manuscript, separate figure/table upload may not be necessary.

## Final submission check

Before clicking final submit, confirm:

- **The uploaded PDF opens correctly.**
- **The uploaded DOCX opens correctly.**
- **All references appear in the manuscript.**
- **All figures appear in the manuscript.**
- **All tables appear in the manuscript.**
- **The supplementary appendix is attached.**
- **The cover letter is attached or pasted.**
- **No placeholder files are included.**
- **No unsupported causal or deployment-readiness claims were added during upload.**
